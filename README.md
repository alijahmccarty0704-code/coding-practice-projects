# Coding Practice Projects

A curated collection of Python and Java CLI projects built while practicing software development, Git, testing, and Linux workflows.

All support scenarios and records use fake, generic data. No employer, customer, or restricted information is included.

## Python Projects

- [Ticket Triage](python/ticket-triage/)
- [Password Reset Queue](python/password-reset-queue/)
- [Failed Login Analyzer](python/failed-login-analyzer/)

## Java Projects

- [Help Desk Checklist](java/help-desk-checklist/)
- [Device Inventory Checker](java/device-inventory-checker/)

## Skills Practiced

- CLI application design
- Input validation and error handling
- Functions and methods
- Lists, nested records, and arrays
- Menu, `for`, and `while` loops
- Counting, searching, and index mapping
- Java compilation and JVM execution
- Git staging, commits, and repository hygiene

## Running the Projects

### Python

Run each Python project from the repository root:

```bash
python3 python/ticket-triage/ticket_triage.py
python3 python/password-reset-queue/passwordreset.py
python3 python/failed-login-analyzer/failed_login_analyzer.py
```

### Java

Run each Java project from the repository root:

```bash
cd java/help-desk-checklist
javac HelpDeskChecklist.java
java HelpDeskChecklist
```

```bash
cd java/device-inventory-checker
javac DeviceInventoryChecker.java
java DeviceInventoryChecker
```
